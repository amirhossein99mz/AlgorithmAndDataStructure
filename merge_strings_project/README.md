# merge_strings.c

This program merges two lowercase alphabetic strings and sorts all characters using Merge Sort.

## Features

- Validation using `isalpha()` and `islower()`
- Dynamic memory allocation
- Recursive merge sort
- String concatenation with `strcpy()` and `strcat()`

## Example

Input:
abcwendwrdxyz
defpwoaaaekwdawgh

Output:
sorted merged string

## Compile

gcc merge_strings.c -o output

## Run

./output
