# Crowded Depth in N-ary Tree

## Description
This program finds the depth containing the maximum number
of nodes in an n-ary tree using BFS traversal with a queue.

It also prints all node values at that depth.

## Functions
- create_node
- free_node
- create_queue
- enqueue
- dequeue
- display_crowded_depth

## Compile

gcc crowded_depth.c -o crowded

## Run

./crowded
