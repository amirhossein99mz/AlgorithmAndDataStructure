# transposeOfListOfList.c

This program implements transpose of a matrix stored as a linked list of linked lists.

## Structures

- `list_t1` → rows
- `list_t2` → columns / values

## Functions

- Create node functions
- Add node functions
- Free memory functions
- In-place transpose for square matrices
- Convert list → matrix → transposed list

## Compile

```bash
gcc transposeOfListOfList.c -o transpose
```
