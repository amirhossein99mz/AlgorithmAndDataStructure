# Matrix Distinct Elements Counter

## Description
This program counts how many times each distinct element appears in a matrix.

## Logic
1. Convert the 2D matrix into a 1D array.
2. Sort the array using Merge Sort.
3. Traverse the sorted array and count repeated values.
4. Print each value with its frequency.

## Example Output
11[2], 12[2], 15[1], 31[4], 32[1], 42[1], 61[1]
